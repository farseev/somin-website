What are Meta's AI connectors?

Meta's AI connectors let an outside AI agent work with your ads account. The ads MCP server is Meta-hosted and uses the Model Context Protocol, which the MCP site describes as an open-source standard for connecting AI applications to external systems.

According to Meta's Ads MCP Server overview, the tools fall into seven groups:

  • Performance reporting and insights
  • Creating and editing ads, ad sets and campaigns
  • Catalogue creation, product data and feed troubleshooting
  • Signal health and quality
  • Searching Meta Business Help Center articles
  • A/B tests and conversion lift studies
  • Ad account activity logs

Meta also lists an Ads CLI for command-line use. This guide covers the MCP server. For the strategic background, read Meta's shift toward open AI connectors.

What do you need before you connect?

You need an ads account, a Meta app with the right use case, and a clear scope. Meta's get-started page lists three requirements:

  1. Create or open an app at developers.facebook.com/apps.
  2. Add the "Create & manage ads with ads MCP server" use case.
  3. Set the app's redirect URL in the Facebook Login for Business settings to match your MCP client.

The same page notes you do not need your own Meta app if you follow Meta's separate help-centre guide on setting up ads AI connectors. Check which route applies to you.

Permissions: the minimum is ads_mcp_management plus ads_read or ads_management. Optional extras include catalog_management, business_management, pages_show_list and instagram_basic. Ask for the smallest set that does the job.

How do you connect it to Claude?

For Claude Code, run one command with your Meta app ID. For other Claude apps, add the URL as a custom connector.

Meta's page gives this Claude Code command:

claude mcp add --transport http --client-id <META_APP_ID> meta-ads https://mcp.facebook.com/ads

Replace the placeholder with your app ID and make sure the app's redirect URL matches Claude Code. Meta's page has no steps for Claude Desktop or claude.ai. Anthropic's custom connectors guide covers those. On Pro and Max plans you go to Customize, then Connectors, then Add custom connector, enter the server URL and choose an authentication option. On Team and Enterprise plans an Owner adds the connector once and each member then signs in individually.

Anthropic's guide also warns that it has not verified custom connectors, that you should connect only to servers from organisations you trust, and that "Allow always" should be used with care. Our guide to connecting Claude to marketing data with MCP covers account scoping in more depth.

How do you connect it to ChatGPT?

Use ChatGPT's developer mode, choose OAuth and enter Meta's server URL. Meta's page gives five steps:

  1. Set your Meta app's redirect URL according to ChatGPT's authentication specification.
  2. Open developer mode, following OpenAI's guide.
  3. Select OAuth as the authentication method.
  4. Enter https://mcp.facebook.com/ads as the server URL.
  5. Under Advanced OAuth Settings, enter your Meta app ID as the OAuth Client ID.

According to OpenAI's developer mode guide, it is available on the web for Pro, Plus, Business, Enterprise and Education accounts, and you enable it under Settings, then Apps, then Advanced settings. OpenAI calls it powerful but dangerous. Write actions need confirmation by default, and you should review each tool input before approving.

How do you connect it to Manus?

Meta does not document Manus, so treat this route as untested until you try it. Manus supports custom MCP servers, and Meta's page says a bearer token works for direct calls, so a token-based connection is the likely path.

The Manus custom MCP page says to go to Settings, then Integrations, then Custom MCP Servers, and click Add Server. You enter a server name, an HTTPS server URL and authentication such as an API key or bearer token. Manus then runs a connection test that retrieves the tool list.

Meta's get-started page says that for programmatic access you can send a user access token in an Authorization header, and that a system user token can be used server to server. It adds that only Employee-role system user tokens work; Admin-role tokens cannot access the server. We could not confirm from either vendor that this exact combination works in Manus, so run the connection test, then a read-only question.

The Manus page also says never to expose credentials in URLs or logs and to rotate credentials regularly. We found no official documentation for a command-line route (manus-mcp-cli), so we leave it out.

How do you check the connection works?

Ask a read-only question. Meta's own suggested test is "List my ad accounts." If the right accounts come back, the connection and the permissions are working.

Then compare one reported number with Ads Manager before you trust any summary. If the figures differ, find out why before you build a workflow on top.

What should stay under human control?

Anything that spends money or changes live campaigns. The connectors can create and edit campaigns, so approval settings matter more than the connection itself.

  • Start with reporting and insights only.
  • Use a narrow account and the smallest permission set.
  • Leave tool approval on for write actions in every client.
  • Treat anything a tool returns as data, not instructions.
  • Know how to revoke access before you grant it.

FAQ

What is Meta's MCP server URL?

According to Meta's developer documentation, the ads MCP server is hosted at https://mcp.facebook.com/ads.

Which AI clients work with Meta's ads MCP server?

Meta says any MCP-compatible AI agent. Its get-started page gives steps for Claude Code and ChatGPT. It gives none for Manus or Claude Desktop.

How do I manage ads from an AI agent with Meta's connectors? (Como gerenciar anúncios de um agente de IA com os conectores de IA de anúncios da Meta?)

Connect a client to the ads MCP server, then ask for reports first and changes later, with approval on. Readers searching for "Meta広告 MCP" (Japanese for Meta ads MCP) will find the same server and the same steps; the connector itself is not region-specific in Meta's documentation.

Do I need to write code?

Not for the OAuth routes: you add a server URL and sign in. Claude Code needs one terminal command. A token-based route, such as one for Manus, needs a system user token.

Is it safe to give an AI agent access to my ad account?

It can be if you use the narrowest permissions, keep approval on for write actions and check results against Ads Manager. Both Anthropic and OpenAI warn about prompt injection and untrusted servers.
