The Marketing Mondays plugin is a free plugin for Claude from SOMIN (SoMin.ai), the AI marketing-intelligence company run by Somin Pte. Ltd. in Singapore. It packs 26 skills, eight of them main skills, that listen to your market, decode competitors, find whitespace, make on-brand creative and plan a content calendar. All of it runs on your own SOMIN data.

Key takeaways

  • The plugin is free to download, but its skills read data through SOMIN, so you need a SOMIN account.
  • It holds 26 skills: eight main skills and 18 helpers the main ones call for you.
  • The workflow is one loop of five steps: listen, decode, decide, make and ship.
  • Setup takes about three minutes in four steps, in Claude on the desktop app or claude.ai.
  • Figma and Postly are optional and only needed for the make and ship steps.

What is the Marketing Mondays plugin?

It is the workflow SOMIN showed live at a Marketing Mondays session, packed into one plugin file called marketing-mondays.plugin. Marketing Mondays is, according to SOMIN's plugin page, a Singapore community of marketers that decodes one real market signal every Monday, with SOMIN as its technology partner.

The plugin packs the workflow shown at the session "The 2027 marketing team: smaller, faster, or obsolete?" on 12 October 2026. You ask for a finished output in plain English, and the matching skill does the work. See the full page at Marketing Mondays plugin.

What are the eight main skills?

Each skill sits in one step of the loop and can run on its own or feed the next. The list below follows the plugin page.

The other 18 skills are helpers, from persona and tension discovery to whitespace analysis, content calendars and deck QA. For the idea behind the whitespace step, read what marketing whitespace is.

Why a five-step loop?

The plugin asks the same four questions every time, on your brand: who are we talking to, what is bugging them, why does it happen, and what is the one line that says it? Every answer comes from data. Each step is a skill you can run on its own or chain into the next.

SOMIN also shows a real run on its site: a Grab Singapore example from a Marketing Mondays session, with one agent skill per step and a strategist choosing what ships. It is a demonstration of the workflow, not a promise of the same result for your brand.

What do you need before you install it?

You need Claude (the desktop app or claude.ai) on a plan that lets you add plugins, and a SOMIN account. Figma and Postly are optional. Without a SOMIN account the skills have no data to read; you can request SOMIN access on the site.

How do you install the Marketing Mondays plugin?

Install it in four steps, which SOMIN says take about three minutes.

  1. Sign in to SOMIN first. Use cloud.somin.ai with the account whose workspaces Claude should see, then open Claude. Claude links to whichever SOMIN account is signed in when you click Connect.
  2. Upload the plugin. In Claude, open Customize › Plugins, click Add › Upload plugin and choose marketing-mondays.plugin.
  3. Connect SOMIN. Open Marketing Mondays in Customize › Plugins and select the Connectors tab. Click Add, then Connect. On a Team or Enterprise plan, ask your Claude Owner to add the SOMIN connector.
  4. Check it works. Ask Claude which SOMIN workspaces it can see. A list of workspace names within a few seconds means you are connected.

If there is no Connectors tab, add SOMIN as a custom connector instead, with the server URL https://cloud.somin.ai/_mcp. Keep the underscore. The wider picture is in the SOMIN MCP server guide.

Does it work in Claude Code?

Yes, according to the plugin page. A plugin added in the Claude app syncs to Claude Code when you are signed in to the same account; run /reload-plugins. Or start Claude Code with its plugin-directory option pointed at marketing-mondays.zip for one session. Then run /mcp, pick SOMIN and sign in. Skills appear as /marketing-mondays:<skill>.

Where does the data come from?

From your SOMIN workspaces: the competitor posts, ads, studies and audience insights SOMIN already tracks for you. SOMIN says every number in the outputs traces back to a SOMIN post, study or ID. The plugin does not replace the data layer; it makes that layer easy to use from Claude. See SOMIN's AI agents for the engine behind it.
