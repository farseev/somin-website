What is the Biblioteca de Anúncios da Meta?

It is Meta's public, searchable archive of ads. In 2019 Meta said the library would show "all active ads any Page is running", and that people could search it by Page as well as by keyword (Meta, 2019).

Brazilian marketers use several search terms for it: biblioteca de anúncios meta, biblioteca meta ads, meta ads biblioteca and biblioteca de anúncios meta ads. All lead to the same tool. Spanish-speaking teams in neighbouring markets look for the Biblioteca de anuncios, which is the same library with a Spanish name.

Meta's 2019 article also says Page information can include the creation date and past name changes. For larger Pages, or Pages running political or issue ads in select countries, it can include the main country of the people who manage the Page. Use that to check who really stands behind a brand.

How do you search the library for competitors in Brazil?

Use the same routine for each rival so your results can be compared.

  1. Open the library and set the country to Brazil. Do not mix countries in one search. Run Portugal separately if you sell there, since the language and offers differ.
  2. Keep the category on all ads, unless you are studying political or social-issue advertising.
  3. Search for the brand. Try the name as customers write it, with and without accents, and any product-line names.
  4. Select the Page from the suggestions. A keyword search can return other advertisers whose ads include the word.
  5. Apply the filters the interface offers, such as status, language or platform.
  6. Open each ad's details and note the start date, the status and the format.
  7. Check the Page information to confirm you have the right entity.
  8. Save the link, the ad ID, a screenshot and the date you captured it.

Meta's help articles block automated reading, so we could not verify them while writing. Control names can change, so confirm each step on screen.

What can you see for Brazilian ads, and what is missing?

You can see what is running now: creative, copy, call to action and Page. You should not assume you will see spend, audience size or results.

For comparison, Meta said in 2023 that all ads targeting people in the EU would be archived for a year, with age, gender and location selections and the dates they ran (Meta, 2023). We found no equivalent statement for ordinary Brazilian ads, which is why regular capture matters.

What should you analyse in Brazilian competitor ads?

Look at the patterns, not single ads.

  • Offer type: discounts, instalment payments, free shipping, free trials. Count each.
  • Language and tone: informal Brazilian Portuguese versus neutral or European Portuguese. Tag humour, slang and regional references.
  • Format: video, static image, carousel, and whether creators appear.
  • Calls to action: buy now, sign up, message us. Which one does each rival lean on?
  • Run length: start dates show how long a rival keeps an idea going.
  • Duplicates: strip out near-identical variations before counting.

What else should you check besides Meta?

Check Google as well, because Meta covers only its own apps. Google describes its Ads Transparency Center as a searchable hub showing the ads a verified advertiser has run, the region they were shown in and the last date they ran (Google).

FAQ

What is the Biblioteca de Anúncios da Meta?

It is the Portuguese name for the Meta Ad Library, Meta's public archive of ads that Pages run on its apps. Brazilian marketers also search for biblioteca meta ads or meta ads biblioteca.

Is the Biblioteca de anuncios the same thing?

Yes. Biblioteca de anuncios, without the accent, is the Spanish name for the same Meta Ad Library. Pick Brazil, or another Latin American country, with the country selector.

Can I see how much a Brazilian competitor spends?

Not for ordinary commercial ads. Meta's spend and reach figures are tied to political and issue ads, and the extra targeting details Meta announced in 2023 apply to ads aimed at the EU.

Will an ad still be there next month?

Do not count on it. Meta described the library as holding active ads, and we found no retention period for ordinary Brazilian ads. Screenshot and log each ad with its date.

How often should I check?

Weekly in fast categories such as retail and fintech, monthly otherwise. Use the same searches each time so changes are easy to see.
