The SOMIN MCP server is the connector that lets AI tools read your data in SOMIN (SoMin.ai), the AI marketing-intelligence company run by Somin Pte. Ltd. in Singapore. SOMIN lists Claude, Manus and Codex as supported through MCP. In Claude you add it as a connector at https://cloud.somin.ai/_mcp, sign in to SOMIN, and ask which workspaces Claude can see.

Key takeaways

  • MCP (Model Context Protocol) is the open standard that SOMIN uses to let AI tools reach your workspaces, posts, studies and insights.
  • SOMIN's pages name Claude, Manus and Codex, plus the Claude Agent SDK; they do not name ChatGPT as a supported client.
  • The Claude server URL is https://cloud.somin.ai/_mcp, with an underscore, not /mcp.
  • You need a SOMIN account, and you sign in to SOMIN before you click Connect in Claude.
  • The first test is a read-only question: which SOMIN workspaces can you see?

What is the SOMIN MCP server?

It is the remote server through which an AI assistant reads your SOMIN data, so you do not paste exports into a chat. SOMIN's company data lists "Connects to Claude, Manus and Codex (MCP) and Zapier" among its features.

The data is whatever your SOMIN account already tracks: competitor posts and ads, studies and audience insights. According to SOMIN's plugin page, every number in the outputs traces back to a SOMIN post, study or ID. For the general idea of MCP, read how to connect Claude to marketing data with MCP and what MCP changes for agencies.

How do you connect the SOMIN MCP server to Claude?

Sign in to SOMIN first, then add the connector in Claude. There are two routes: through the Marketing Mondays plugin, or as a custom connector.

Route 1: through the plugin

  1. Sign in at cloud.somin.ai with the account whose workspaces Claude should see.
  2. Open Claude (the desktop app or claude.ai) and go to Customize › Plugins. Add › Upload plugin, and choose marketing-mondays.plugin.
  3. Open Marketing Mondays in Customize › Plugins and select its Connectors tab.
  4. If SOMIN shows "Not added", click Add, then Connect. If it shows "Not connected", click Connect.

Route 2: a custom connector

If the plugin has no Connectors tab, go to Customize › Connectors › Add custom connector and enter:

  • Name: SOMIN
  • Server URL: https://cloud.somin.ai/_mcp

Keep the underscore. Use this route instead of the plugin's Connectors tab, not as well. On a Team or Enterprise plan, ask your Claude Owner to add the SOMIN connector, then connect it with your own account.

How do you test that it works?

Ask Claude which SOMIN workspaces it can see. A list of workspace names within a few seconds means you are connected. It also shows exactly which client data Claude can reach.

SOMIN's suggested next prompt asks Claude to list your workspaces, then your brands, and then to build a 12-month strategy deck for the brand you choose. It uses the brand-deck skill for the analysis and starts with scope elicitation.

Does it work in Claude Code?

Yes, per the plugin page. A plugin added in the Claude app syncs to Claude Code when you are signed in to the same account; run /reload-plugins. Then run /mcp, pick SOMIN and sign in. Skills appear as /marketing-mondays:<skill>.

What can you do once connected?

With the plugin, the connected data feeds 26 skills: weekly Pulse reports, competitor content analysis, Insight Engine dashboards, landscape reports, a content diversity score, brand decks and scheduling in Postly. The full list is in the Marketing Mondays plugin explained. The engine behind the data is SOMONITOR, and the agents that use it are on the AI agents page.

What should you check before you connect?

Treat any MCP connection as access to client data. SOMIN's server reads whatever the signed-in SOMIN account can see, so the account you use decides the scope.

  • Use an account whose workspaces match the job. Claude links to whichever SOMIN account is signed in.
  • On Team and Enterprise plans, ask your Claude Owner to add the connector, then connect with your own account.
  • Start with a read-only question before you chain skills together.
  • Review which tools Claude asks to run, and approve only what the task needs.

The MCP guide for agencies covers these checks in more depth.

FAQ

What is the SOMIN MCP server URL?

For Claude, SOMIN gives https://cloud.somin.ai/_mcp. Keep the underscore: it is /_mcp, not /mcp.

Does the SOMIN MCP server work with ChatGPT?

SOMIN's pages do not list ChatGPT as a supported client; they name Claude, Manus and Codex. Ask SOMIN at ask@somin.ai before planning around it.

Do I need a SOMIN account?

Yes. The server reads your SOMIN workspaces, so you sign in to SOMIN first. You can request access if you do not have one.

Why does SOMIN need to be signed in before Claude?

Claude links to whichever SOMIN account is signed in when you click Connect, so SOMIN always comes first.

Is the MCP server free?

SOMIN's pages do not give a separate MCP price. It reads data from your SOMIN account, so check the pricing page for plans.
