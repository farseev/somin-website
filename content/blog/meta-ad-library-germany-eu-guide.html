What is the Meta Werbebibliothek?

It is the German-language name people use for the Meta Ad Library, the searchable archive of ads that Pages run on Meta's apps. Searches for "meta werbebibliothek" and "meta anzeigenbibliothek" lead to the same library.

When Meta widened the library in 2019, it said it would hold all active ads that any Page is running, with search by Page as well as by keyword (Meta, 2019). It also described Page information, including the Page's creation date and name changes.

What is different about ads in Germany and the EU?

Ads that target people in the EU are archived longer and with more detail. In August 2023, as the Digital Services Act came into effect, Meta said it would display and archive all ads that target people in the EU. It said they would stay in the public library for a year, and that entries would include age, gender and location selections and when each ad ran (Meta, 2023).

Germany is an EU member state, so an ad aimed at people in Germany falls under that description. This is our reading of Meta's statement, not a separate Germany rule we found on a Meta page. The exact fields shown can change, so check the ad detail page you see.

How do you search the Werbebibliothek for a German competitor?

Follow the same short routine for every competitor.

  1. Open the library and set the country to Germany. If you also sell in Austria or Switzerland, run those as separate passes. Switzerland is not in the EU, so do not assume the EU archive rules apply there.
  2. Keep the category on all ads. Use the political and issue categories only when you study that topic.
  3. Search the advertiser by name. Try the German brand name, the English name and any product-line Pages.
  4. Select the Page itself. A keyword search can also return other advertisers whose ads use the word.
  5. Filter with the controls the interface offers, such as status, language or platform.
  6. Open the ad details and copy the link, ID, start date and the targeting details if shown.
  7. Check the Page information to confirm the right legal entity and see name changes.
  8. Screenshot every ad with the capture date.

Meta's own help articles block automated reading, so we could not check them while writing. Treat the interface labels as indicative and confirm them on screen.

What should you analyse once you have the ads?

Look for patterns in messages, formats and audiences, not individual ads.

  • Message mix: price, quality, sustainability, trust, convenience. Count how often each appears.
  • Language: German-written copy versus translated English. Formal "Sie" versus informal "du" is a tone choice worth tagging.
  • Targeting clues: for EU-targeted ads, note the age, gender and location selections shown. Use them as hints about the audience a rival wants, not as proof of results.
  • Run length: start dates show how long a rival keeps an idea in market.
  • Duplicates: deduplicate near-identical variations before you count.

What does the library not cover?

It covers Meta only. Google describes its Ads Transparency Center as showing the ads a verified advertiser has run, the region where they were shown and the last date they ran, across Search, YouTube and Display (Google). You need both to see a rival's paid presence.

Neither shows results. Spend, conversions and creative performance for a competitor are not public, so pre-test your own ideas. FAQ

Is the Meta Werbebibliothek the same as the Meta Ad Library?

Yes. Werbebibliothek and Anzeigenbibliothek are German names for the same public Meta Ad Library.

How long are ads for Germany kept?

Meta said in 2023 that ads targeting people in the EU stay in the public library for a year. Germany is an EU country, so that statement applies to ads aimed at German users.

Can I see the targeting of a German competitor's ads?

Meta said EU entries would include age, gender and location selections. What you see on each ad can differ, so check the ad details. Interest-level targeting is not something we could confirm.

Do I need to search in German?

Search the brand name, which usually works in any language. Then read the ads in German and tag message and tone. Machine translation can hide differences in formality.

Does the library show how well competitor ads perform?

No. It shows what is running and when it started, not conversions or return. Use it to understand competitor messaging, then test your own creative.
